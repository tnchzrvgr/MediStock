Put the Chart.js file here, named: chart.umd.js

How to get it (one time, with internet):
1. Open this link in your browser:  https://cdn.jsdelivr.net/npm/chart.js
2. Press Ctrl + S and save the page as  chart.umd.js  in this folder (public/js).

After that the charts also work without internet.


Face login also needs this file here, named: face-api.min.js
Link: https://cdn.jsdelivr.net/npm/face-api.js@0.22.2/dist/face-api.min.js
(open it in the browser, Ctrl + S, save as face-api.min.js)
The model files go to public/models (see the README.txt there).
